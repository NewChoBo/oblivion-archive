# 챕터 1 심우주 스카이박스

여섯 면은 각 1024×1024, 원통형 경위도 파노라마는 4096×2048이다. 둘 다 sRGB PNG다. 다른 엔진에서 큐브맵을 조립할 때는 파일 이름의 축 부호와 아래 방향을 사용한다. 배경용 텍스처로 연결하면 서쪽 전망탑 방향에 은청색 성운이 온다.

성운 원화는 방위각 −78°, 고도 +10°를 중심으로 약 64°×30° 범위에 들어간다. 별 3,300개는 같은 시드로 구면 위에 배치한다. 게임에서는 원본과 주변을 평균한 낮은 해상도의 샘플을 비교해 별 중심부를 찾는다. 방향별로 주기가 다른 두 밝기 파동이 겹쳐 별빛이 일렁인다. 동작 줄이기 설정에서는 시간을 멈춘다. PNG는 다른 엔진에서 정적인 배경으로 쓸 수 있다.

배경 셰이더는 하늘의 화면 색을 계산한다. 성곽의 간접광과 반사 밝기는 별도로 설정한 환경 프로브와 반구형 광원을 사용한다.

| 파일 | 면 중앙 | 이미지의 위 | 이미지의 오른쪽 |
| --- | --- | --- | --- |
| `space_px.png` | +X | +Y | −Z |
| `space_nx.png` | −X | +Y | +Z |
| `space_py.png` | +Y | −Z | +X |
| `space_ny.png` | −Y | +Z | +X |
| `space_pz.png` | +Z | +Y | +X |
| `space_nz.png` | −Z | +Y | −X |

`space-panorama.png`는 중앙이 +Z이고 왼쪽 1/4이 −X다. 위쪽 끝이 +Y, 아래쪽 끝이 −Y다. 챕터의 좌표계는 +X가 오른쪽, +Y가 위, +Z가 앞이다.

Pillow와 NumPy를 설치한 다음 `babylon/`에서 `python tools/build-chapter-skybox.py`를 실행하면 `nebula-source.png`로 두 형식을 다시 만들 수 있다.
