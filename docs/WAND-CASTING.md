# 봉인의 수정 완드 · 시전 모션 조사

2026년 11월 22일. 챕터 1의 서기관이 잉크 그림자에 주문을 걸 때, 완드를 든 오른손만 보아도 무엇을 하는지 알아볼 수 있는 동작을 검토했다.

이 조사 이후 기본 완드에 한 획 시전을 적용했다. 오른손이 기본이며, 설정에서 왼손을 선택하면 1·3인칭 동작과 3인칭 어깨 시점이 함께 바뀐다. [적용 빌드의 동작 비교](validation/index.html#handedness)

## 조사 당시 완드가 조준처럼 보였던 이유

정면과 측면 캡처를 보면 휴대할 때는 수정 끝이 위로 향한다. 발사 순간에는 팔꿈치가 몸 앞에 나오고 완드가 거의 수평이 된다. 정면에서는 수정 끝이 손에 겹쳐 완드의 길이까지 잘 보이지 않는다. 1인칭에서는 손잡이 뒤쪽이 크게 보이고 수정 끝은 조준점 쪽으로 짧아져 보인다. [정면·측면 캡처](validation/2026-11-22/arcane-tools/wand-profile.webp) · [1인칭 캡처](validation/2026-11-22/arcane-tools/first-wand.webp)

첫 발이 대기 중이면 준비 자세의 비율을 그 프레임에 1로 올린다. 우클릭, 좌클릭 유지, 발사 직후 0.22초가 같은 자세를 요청한다. 완드의 반복 사용 간격은 0.28초다. 3인칭 팔이 추가로 뻗는 움직임도 주문이 나간 뒤에 시작하므로, 플레이어가 가장 먼저 보는 동작은 완드 축이 목표를 향해 정렬되는 순간이다. ## 서기관에게 맞는 한 획

서기관이 공중에 짧은 글자를 쓰듯 **손목을 들어 획을 준비하고, 팔꿈치로 얕은 사선을 이끌고, 수정 끝으로 마지막 점을 찍는 동작**을 권한다. 주문이 손을 떠나면 손목은 획의 방향으로 조금 더 흐른다. 완드와 손가락이 함께 만들어 내는 옆모습을 1·3인칭에서 모두 볼 수 있다.

아래 시간은 현재의 0.28초 반복 간격에 맞춰 시제품에서 시험할 제안값이다.

| 입력 이후 | 1인칭에서 보이는 동작                                                   | 3인칭에서 보이는 동작                                                                                |
| --------- | ----------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| 0–70ms    | 클릭과 동시에 오른쪽 아래에서 손목이 들리고 수정에 작은 빛이 맺힌다.    | 오른팔 팔꿈치가 살짝 열리고 손이 몸통 윤곽 밖으로 나온다.                                            |
| 70–100ms  | 수정 끝이 조준점 옆에 짧은 사선을 긋는다. 획을 맺을 때 주문이 출발한다. | 가슴이 조금 따라 돌고 팔꿈치, 손목, 수정 끝 순서로 획이 완성된다.                                    |
| 100–280ms | 손목이 사선 아래로 흘러 중앙 시야가 열린다.                             | 팔이 부드럽게 접힌다. 연속 사용 시 다음 획을 반대 사선으로 연결해 같은 정지 자세로 튀는 일을 피한다. |

우클릭은 대상을 정하고 있는 **집중 자세**로 해석한다. 완드는 몸 옆에 비스듬히 들고, 클릭을 놓아도 이미 시작한 한 획은 끝까지 이어진다. 실제 주문은 획이 맺히는 프레임의 수정 끝에서 조준점 쪽으로 출발한다. 가까운 문틀이나 바닥에 먼저 닿으면 그 표면에 효과가 생긴다. 룬 활은 화살받침과 시위를 잇는 선이 조준 방향을 보여준다. [기존 표면 적중 처리](../babylon/src/platform/babylon/effects/spell-effects.ts)

## 시제품 판정 장면

- **열람실 기록대 앞**에서 이펙트를 잠깐 끈 채 1인칭 단발을 본다. 손이 들리고 획이 끝나는 순간이 구분되며, 사진과 책등을 살필 중앙 시야가 열려야 한다.
- **회랑에서 옆걸음으로 세 번 연속 사용**한다. 3인칭 측면에서 팔꿈치와 수정 끝이 그리는 호가 보이고, 발걸음은 이어져야 한다. 짧게 한 번 눌러도 주문 한 발이 끝까지 나가야 한다.
- **발밑과 문틀 모서리**에 각각 시전한다. 두 시점에서 궤적의 시작과 수정 끝이 같은 프레임에 만나고, 문틀 뒤쪽으로 빛이 새지 않아야 한다. 마지막으로 기본 시전과 충전을 소리 없이도 구별할 수 있는지 본다.
