# 챕터 1 · 사진에서 지워진 사람

목표는 한 장의 사진에서 지워진 서기관의 이름을 되돌리는 한 번의 공간 탐험이다. 열람실 북쪽 아치에서 동쪽으로 꺾이는 회랑을 따라 원본 서고에 들어가고, 남쪽 빗장을 풀어 열람실로 돌아온다. 툼레이더의 공간 관찰과 바이오하자드의 귀환 지름길을 구성 참고로 삼았다.

| 구역                  | 플레이와 통행                                                                                                                       |
| --------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| 열람실                | 사진 조사, 서가와 중앙 책상 우회, 조작 익히기, 북쪽 아치 개방                                                                       |
| 남쪽 성곽             | 대서고 테라스에서 두 단의 계단을 내려가 천구 광장으로 간다. 서쪽 성곽길은 천문대, 쌍탑 관문과 세 아치의 석교는 도착섬으로 이어진다. |
| 제본 공방과 하역 창고 | 성문 광장에서 두 작업동으로 들어갈 수 있다. 서쪽은 압착기와 종이 건조대, 동쪽은 운반 상자와 절벽 밖 권양기로 용도를 구분한다.       |
| 대서고                | 상부 단구에서 본관과 두 날개로 진입한다. 서쪽 열람동에는 독서대와 벤치, 동쪽 서고에는 원본 서가가 있다.                             |
| 무너진 회랑           | 벽화의 세 위치 관찰, 낮은 돌턱 점프·옆 우회, 잉크 그림자 회피·완드 봉인                                                             |
| 봉인 앞               | 밝은 피난 구역에서 세 받침을 회전시키는 환경 퍼즐, 일치 후 문 개방                                                                  |
| 보관실                | 서명 원부에서 이름 수집, 깨어난 그림자를 피해 남쪽 빗장으로 이동                                                                    |
| 귀환 통로             | 원본 서고의 공개 서가로 나온 뒤 서쪽 연결문으로 본관 재진입                                                                         |
| 기록대                | 이름을 기록해 두 사람이 있는 사진과 엔딩 복원                                                                                       |

사진 조사가 끝나면 쌍탑 등불이 켜진다. 봉인을 열면 제본 공방의 작업등과 건조 중인 종이가, 원부를 읽으면 서고의 장서와 창빛이 돌아온다. 귀환 빗장을 풀면 하역장의 상자가 올라오고 이안의 이름을 적으면 대서고의 별창에 여덟 갈래 문양이 나타난다. 열람실 북쪽 아치 옆 부조에도 같은 다섯 장면이 순서대로 밝아진다.

사진 조사·보관실 개방·원부 수집·지름길 개방·엔딩에서 체크포인트를 저장한다. 실패나 일시정지에서 재도전하며, 새 페이지에서는 이어하기를 선택한다. 미완료 봉인 회전은 마지막 체크포인트로 되돌아간다. 위치·시점·도구 모드는 일반적인 이동·전환과 별도로 다루고, 체크포인트는 안전한 고정 위치에서 시작한다.

서재와 성곽, 회랑, 보관실, 귀환 통로에는 설정집 기록 여덟 편이 있다. 제본 공방에는 수선표가, 하역 창고에는 별항로 전표가 남아 있다. 손이 닿는 거리에서 상호작용해 수집한다. 장부의 설정집 탭에서 읽거나 미발견 기록의 단서를 볼 수 있다. 수집은 브라우저에 기록별로 저장하며, 체크포인트 재도전과 챕터 재시작 뒤에도 이어진다. [기록 내용과 배치](../shared/levels/chapter-1-codex.json)

기둥·서가·잔해·문·천장은 Babylon 충돌을 설정한다. 아치는 쐐기와 양옆 석주에 판정을 두어 개구부를 비워 둔다. 열린 문은 이동·발사·카메라의 장애물에서 빠진다. 3인칭 카메라는 현재 활성 충돌체의 경계를 매번 읽는다.

도착섬 서쪽 선착장에서 별바다로 추락하면 게임 오버 화면이 열린다. 첫 기록 전에는 선택한 시작 지점에서 재도전한다. 체크포인트가 있으면 해당 단계의 위치에서 재개한다. [대서고 지상층과 귀환 동선](art/chapter-1/library-route.svg)

## 환경 에셋과 씬 배치

공용 제작 기준과 벽 개구부 작성법은 [레벨 제작 원칙](LEVEL-DESIGN.md)에 정리했다.

- [환경 프리팹](../shared/levels/environment-prefabs.json)에 공용 재질, 재사용하는 박스·바닥 형상, 충돌 여부와 GLB 경로를 정의한다. 모델 경로는 저장소의 `public/` 기준이다. 모델이 있는 프리팹은 첫 번째 박스를 충돌체로 사용하고, 모델 원점을 박스 밑면 중앙에 맞춘다. `fitToBox`는 단위 크기로 제작한 잔해 모델을 충돌 박스의 세 변에 맞춘다.
- [챕터 씬](../shared/levels/chapter-1.json)은 구역별로 고유한 `id`와 프리팹 키를 지정한다. `position`은 기준점의 월드 좌표, `size`는 X·Y·Z 순의 전체 크기, `offset`은 프리팹 부품의 기준점 기준 오프셋이다. 단일 박스에 `bounds`를 쓰면 각 축의 최소·최대값에서 중심과 크기를 계산한다. `model.yawDegrees`와 `model.scale`은 보이는 모델에 적용하며 충돌체에는 영향을 주지 않는다.
- [Babylon 연결 코드](../babylon/src/platform/babylon/chapter/chapter-scenery.ts)는 위 데이터를 읽어 메시와 충돌체를 만들고, 같은 GLB를 한 번 읽어 재사용한다. 문 열림 같은 동작은 [챕터 런타임](../babylon/src/platform/babylon/chapter/chapter-world.ts)이 배치 ID로 해당 오브젝트를 찾아 실행한다. 특수 아치, 표지, 사진, 조명과 퍼즐 동작은 챕터 코드에서 관리한다.

배치 좌표는 미터 단위의 왼손 좌표계이며 오른쪽 +X, 위 +Y, 정면 +Z다. Unity에서는 프리팹과 씬 인스턴스, Unreal에서는 Static Mesh와 충돌 컴포넌트를 가진 Actor로 대응시킬 수 있다. Unreal 좌표로 옮길 때는 정면 +X, 오른쪽 +Y, 위 +Z에 맞춰 위치·크기·회전을 변환하고 미터를 센티미터로 환산한다. GLB 자체의 좌표 변환은 대상 엔진의 glTF 임포터가 처리한다. [Unity 프리팹 문서](https://docs.unity.com/en-us/engine/6000.0/manual/working-with-gameobjects/prefabs) · [Unreal 좌표계 문서](https://dev.epicgames.com/documentation/en-us/unreal-engine/coordinate-system-and-spaces-in-unreal-engine) · [Unreal 임포트 단위](https://dev.epicgames.com/documentation/en-us/unreal-engine/datasmith-import-options-in-unreal-engine)

완료 조건은 일반 시작 메뉴에서 다섯 구역을 지나 관찰 퍼즐·회피 가능한 위협·지름길·사진 복원 엔딩을 플레이하고, 체크포인트 재도전을 사용할 수 있는 것이다. 설치·개발 서버·빌드와 Orca 내장 브라우저 실입력 증거를 각각 확인한다. 잠금 등 호스트에서 거절한 동작은 성공으로 간주하지 않는다.
