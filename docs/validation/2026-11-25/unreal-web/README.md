# Unreal 5.9 Preview 2 · 웹 빌드 검증

게임 소스 `9fa100e`를 Epic Launcher의 Unreal Engine 5.9.0 Preview 2(CL 60738873)로 빌드했다. 런처는 11월 25일 00:53 KST에 설치 파일 검증을 마쳤다. Turnkey가 Wasm SDK 6.0.10을 유효한 버전으로 확인했고, Shipping 빌드·쿠킹·패키징·아카이브가 성공했다. 쿠킹은 오류 0건·경고 0건이었다.

첫 빌드에서는 밝은 사진 앞에서 금색 안내를 읽기 어려웠다. 깃펜 받침과 귀환로에는 단색 바닥과 석재 포장이 같은 높이에 겹쳐 톱니 모양으로 보였다. 마우스로 회전하고 아래를 조준할 수 있었으나, Orca가 포인터 잠금을 해제한 뒤에는 Esc로 일시 정지해 커서를 옮기고 Enter로 재개했다. [수정 전 룬 바닥](rune-floor-before.png)

## Fab 에셋을 적용한 빌드

게임 커밋 `8a65eeb`의 Shipping 쿠킹은 오류·경고 0건으로 끝났다. Wasm 쿠커의 자산 레지스트리에서 가져온 메시 2종, 재질 3종과 텍스처 9종을 확인했다. Wasm 실행 파일의 SHA-256은 `a67d1ca742209ec799fc40cde1f423f58157f1412c883b2c63c4d168c9709ff4`, 쿠킹한 콘텐츠 컨테이너 `OblivionArchive-Wasm.ucas`는 `bbbcedcaae7bd4fe3d0078fd5d47ae3b1732260fc1a8534dabf9397463845b3f`다.

네이티브 `-RequireFab` 검사 48개가 통과했다. 열람실·보관실의 서가 16칸이 도면 경계에 맞고, 화물 상자 5개는 운반대에 놓여 각각 충돌면 하나만 가진다. 바닥 경계 7점, 봉인문, 귀환과 사진 복원도 함께 검사했다. Babylon 검사는 161개, 레벨 검사는 13개가 통과했다.

Orca에서 새 게임을 시작해 사진을 조사한 뒤 양쪽 서가로 다가갔다. 목재 기둥과 선반의 결, 선반에 얹힌 책을 확인했다. 책등은 단색이며 조명에서 먼 쪽은 어둡게 보인다. [열람실 서가 근접](fab-bookcases-ko.png)

사진 조사 후 열린 북쪽 아치를 지나 회랑에 들어갔다. 북쪽 벽과 개구부 안쪽에 석재 줄눈이 보였다. 가운데 룬 앞에서 아래로 조준했을 때 타일 경계가 곧게 이어졌고, 금빛 룬 위의 E 안내는 짙은 배경에 표시됐다. [북쪽 아치](fab-north-arch-ko.png) · [룬 받침과 바닥](fab-rune-floor-ko.png)

같은 세션에서 봉인문을 열고 서명 원부에서 이안의 이름을 읽었다. 빗장을 연 뒤 지름길로 열람실에 돌아와 원래 사진에 이름을 적자 복원 일러스트와 한국어 엔딩이 표시됐다. [개선판 엔딩](fab-ending-ko.png)
