# Unity 첫 구간 플레이 검증

Unity 6000.6.0f1으로 `83ff964`의 Web 플레이어를 빌드했다. 한국어로 연 Orca 내장 브라우저에서 Enter로 시작한 뒤 WASD와 방향키로 이동·회전하고 E로 조사했다.

| 구간 | 확인한 결과 |
| --- | --- |
| 열람실 | 사진에 접근해 E를 누르면 사진 뒷면의 글이 하단에 나오고 목표가 봉인 조사로 바뀐다. [실제 화면](photograph.png) |
| 회랑 | 기록대 왼쪽을 우회해 도면 폭 2.24m인 북쪽 아치를 통과하고 동쪽으로 이동했다. 씬 생성 시 같은 통로의 기립 캡슐 통과와 오른쪽 벽면 충돌도 검사한다. |
| 보관실 | 봉인을 바라보고 E를 눌러 문을 열었다. 문을 지나 보관실 안으로 들어간 좌표는 X 13.611m, Z 10.372m였고 진행 상태는 `vault-open`이었다. [실제 화면](vault.png) |

검증 주소의 `?inspect=1`은 입력 결과의 좌표·시점·진행 상태를 읽을 때 사용한다. 첫 배포본의 데이터 SHA-256은 `fdbe7dae150c4091c29e6bd07cd0cd327b936d4aae5e57bb4fcce880ceb394b4`, WebAssembly SHA-256은 `f3e0d41fb48f7d26047de844a5a1ac3cf0e41422bc1be44f283d6b9e95a273bd`이다.

별도의 로컬 시험에서는 Stylized Village Fatpack의 벽돌 아치 LOD0를 Unity에서 GLB로 옮겼다. Babylon과 Unity의 외곽 치수 및 825개 광선 판정이 일치했다. 제작자 프리팹의 충돌체는 보이는 개구부 안쪽의 광선 264개를 차단했고, 모델 전체 폭도 1.733m였다. 이에 따라 플레이 장면의 아치는 공유 도면에서 외형과 충돌면을 함께 생성한다. 이 변환 시험의 범위는 정적 형상과 광선이다.
