플레이에는 Orca가 전송한 키·마우스 입력과 자유 시점을 썼다. 위치와 진행도는 읽기 전용 스냅샷으로 확인했다. 통합 상태의 `npm test`는 98개 모두 통과했고 `npm run build`는 게임과 갤러리를 빌드했다.

이전 통합 빌드 `main-DpjH_Pre.js`에서는 첫 채석장 피격 직후 자막 호출에서 예외가 발생해 화면 갱신이 멈췄다. 자막을 채석장보다 먼저 초기화한 뒤 같은 저장·전이·사격 경로로 처치를 확인했다. [탭 콘솔](console.json)에는 이전 빌드를 조사할 때의 예외도 남아 있다.

Orca 실입력에서 남은 경우는 포인터 잠금, 완드 충전 마지막 프레임의 사망, 두 탄종을 모두 소진한 뒤의 긴급 보급, 과거 사용자 세이브 불러오기다. 성채 인양 중 탑승·재도전과 양쪽 어깨의 전체 동작 범위는 [성채 기록](../world/REPORT.md)에, 왼손 무기와 이동하는 문의 검증 범위는 [전투 기록](../combat-followup/README.md)에 있다.
