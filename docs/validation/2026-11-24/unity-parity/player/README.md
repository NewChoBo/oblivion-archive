# Unity 플레이어와 무기 검증

Orca 내장 브라우저에서 새 저장 환경으로 한국어판을 시작했다. 검증한 WebAssembly의 SHA-256은 `4b33de0f2a7f545f6117aa32222753fc33f73cc1e57c79fdcdc5f25b0aaf0d75`이다. 화면은 1205 × 931이었다. 이동, 조준, 사격, 메뉴 조작에는 브라우저의 실제 키와 마우스 입력을 사용했다. [입력별 상태와 빌드 해시](checks.json)

| 항목 | 확인한 동작 |
| --- | --- |
| 시점과 조준 | 1인칭 완드는 중앙 사진에 적중했다. 3인칭으로 전환한 뒤 두 번째 발사는 새 조준점에 있던 아치 벽에 적중했다. 카메라를 왼쪽 어깨로 바꿔도 오른손은 유지됐고, 이어서 왼손을 별도로 선택했다. [1인칭 완드](first-person-wand.webp) · [3인칭 전신과 사진에 남은 주문](third-person-wand.webp) |
| 자세와 활 | 서 있는 상태에서 Z를 눌러 엎드리고, 다시 Z로 일어났다. 활을 누르는 동안 장탄 수와 발사 수가 유지되고 당김이 100%가 됐다. 손을 떼자 화살을 발사하고 예비 화살 하나를 시위에 걸었다. 점프 중 위치 표본의 최대 높이 차이는 0.548m였다. [엎드린 전신과 최대 당김](prone-bow-full-draw.webp) · [왼손 설정의 1인칭 활](left-hand-bow.webp) |
| 손과 상하 시야 | 방향키로 위와 아래 한계에 도달했다. 두 프레임에서 왼손과 완드가 화면 안에 유지됐다. [천장 방향 −84°](viewmodel-ceiling.webp) · [바닥 방향 +84°](viewmodel-floor.webp) |
| 유한 탄약과 소리 | 완드와 활을 합쳐 25회 발사했다. 활의 장탄과 예비 화살을 모두 소진한 뒤 입력해도 발사 수가 증가하지 않았다. 브라우저에서 실제 재생한 오디오를 Web Audio 분석기에 연결해 완드 발사, 활 당김, 화살 발사, 충전·시위 걸기, 빈 완드(0.110초), 빈 화살통(0.055초)에서 각각 신호를 측정했다. |
| 설정과 가방 | 전진을 S에 지정하자 후진이 W로 교환됐다. 페이지를 다시 연 뒤에도 S로 +1.749m, W로 −1.749m 이동했고, 언어와 감도 2.23도 유지됐다. 기본값 복원 후 W로 +1.752m, S로 −1.752m 이동했다. Tab으로 가방을 열고 닫았으며 Esc로 일시 정지했다. [설정 측정값](settings.json) · [재시작 뒤의 설정 화면](settings-after-reload.webp) |

캔버스 클릭은 Pointer Lock을 요청했고 Orca가 `WrongDocumentError`를 반환했다. 이 호스트에서 커서 중앙 고정과 Esc 잠금 해제는 검증할 수 없었다. 방향키 시점 조작으로 나머지 검증을 마쳤다.
