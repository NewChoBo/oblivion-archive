# Unity 탐사 실플레이

Orca 내장 브라우저에서 새 한국어 게임을 시작했다. 사진을 조사하기 전에 열람실에서 보급함, 미라, 채석장, 개인 보관함을 차례로 이용했다. 키와 마우스로 조작하고 Unity가 보고한 자세와 저장 장부를 읽어 결과를 기록했다. 각 캡처의 화면 크기와 당시 저장값은 [검증 기록](checks.json)에 들어 있다.

| 경로 | 확인한 결과 |
| --- | --- |
| 열람실 | Tab으로 장부를 열고 닫았다. 같은 자리에서 M으로 미니맵만 켜고 껐다. 서쪽 보급함에 두 번 상호작용해 탐측 완드 1개와 예비 탄약 12개·10개를 받았다. 미라와 대화하자 의뢰가 시작됐다. |
| 채석장 | 포털 건너편에 체력 72인 망령 셋이 나타났다. 첫 완드 헤드샷으로 체력 52가 줄었다. 총 6회 발사로 세 마리를 처치해 완드 장탄이 0이 됐고 기술 점수 1을 얻었다. R로 재충전하고 북동쪽 상자에서 사냥꾼 활을 얻었다. |
| 귀환과 성장 | 남쪽 포털로 돌아와 미라에게 의뢰를 두 번 제출했다. 보상은 한 번 지급됐다. 기술 점수 1을 집중에 투자하고 탐측 완드를 착용했다. 기존 기록 완드는 동쪽 개인 보관함으로 옮겼다. |
| 사망과 재도전 | 두 번째 원정의 안전 구역을 벗어나 망령에게 맞았다. 첫 피격에 체력과 방어구가 각각 9 줄었다. 사망 후 Enter로 열람실에 복귀했고 체력은 100, 방어구는 0이었다. 탄약, 보상, 보관함, 스킬, 착용 장비가 사망 직전과 일치했다. |
| 사진 조사 전 재접속 | 탐사만 진행한 저장을 가진 채 업데이트 빌드를 다시 열었다. 제목 화면에 ‘이어하기’가 표시됐다. Enter로 복귀한 후 탐사 장부의 모든 필드가 재접속 전과 일치했다. |
| 세로 화면 | 360×740 화면에서 장부를 열고 닫았다. 세로 공간을 활용해 글자 16px와 버튼 최소 높이 40px를 유지하고, 탭과 닫기 버튼을 한 화면에 표시했다. [세로 화면 캡처](24-portrait-ledger.png) |

첫 빌드에서 전투와 원정 동선을 확인하고, 두 번째 빌드에서 사진 조사 전 저장의 복원을 확인했다. 세 번째 빌드에서는 같은 저장을 이어 360×740 장부를 확인했다. 각 빌드에서 탭이 실제 내려받은 데이터 파일과 WebAssembly 파일의 크기를 [검증 기록](checks.json)에 남겼다.
