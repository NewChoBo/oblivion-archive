# 사진에서 지워진 사람 · 퍼즐과 기믹 배치

이 장에서 사라진 것은 사람이 살았던 기록이다. 플레이어는 열람실의 빈 사진을 보고, 기록을 보존하던 사람들의 흔적을 따라 원부에서 이름을 찾는다. 선택 탐험에서 얻는 도구와 보상이 없어도 이 사건은 끝까지 풀 수 있다.

## 현재 본편

| 장소와 시나리오           | 플레이어가 보고 하는 일                                                                                   | 세계관에서의 이유와 결과                                                                         |
| ------------------------- | --------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| 열람실 · 처음 발견한 사진 | 다른 인물 옆에 비어 있는 자리를 보고 액자를 조사한다. 사진 뒷면을 읽은 뒤 북쪽 아치로 간다.               | 사진은 이름과 인물의 기억이 이어진 유물이다. 기록이 돌아오기 시작하면 성문 쌍탑의 등불이 켜진다. |
| 무너진 회랑 · 봉인문 앞   | 북벽 양각에서 등불·깃·물결의 순서를 읽고 세 받침의 표식을 맞춘다. 틀리면 같은 자리에서 다시 돌릴 수 있다. | 찾고, 적고, 보내는 세 동작은 서기관의 일이다. 옆 장식에는 같은 세 표식을 쓰지 않는다.            |
| 회랑 · 잉크 그림자        | 달려서 잔해를 우회하거나 도구로 그림자를 잠시 묶는다. 봉인선을 지나 멈추고 받침을 조사한다.               | 훼손된 기록의 잉크는 봉인이 남은 자리까지 따라오지 못한다. 탄약이 떨어져도 길이 열려 있다.       |
| 봉인 보관실 · 이안의 원부 | 책상에서 이름을 찾고 그림자가 깨어나면 남쪽 빗장으로 향한다. 돌아서 문을 볼 때는 빗장만 선택돼야 한다.    | 원본을 맡는 사람이 안에서 잠그던 문이다. 열면 원본을 열람실로 나르던 짧은 통로를 발견한다.       |
| 중앙 기록대 · 귀환        | 기록대 동쪽 끝을 돌아 액자 앞에서 이름을 돌려준다. 시작 때와 같은 구도에서 두 인물을 본다.                | 첫 방문 때 보았던 빈자리가 채워진다. 복원 단계는 서고의 책등, 하역기, 마지막 별창에도 남는다.    |

## 추가 후보

| 우선도와 위치             | 물건·단서 → 행동 → 변화                                                                                                                                     | 플레이 경험과 검토할 허점                                                                                                                                        |
| ------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 우선 · 제본 공방          | 끊어진 실, 흩어진 접지 세 묶음, 첫 장에 남은 바느질 구멍 → 구멍이 이어지는 순서로 접지를 봉철대에 놓는다 → 사서가 무엇을 고치던 중이었는지 메모가 이어진다. | 주인공의 빈 기억을 손으로 재구성하는 선택 퍼즐. 종이색 외에 구멍의 위치와 장의 가장자리로도 구분한다. 실패한 장은 바로 꺼낼 수 있다.                             |
| 우선 · 동쪽 하역장        | 섬 밖에 매인 책 상자와 창고 앞 빈 착지면 → 들어 올리고, 90° 돌리고, 내린다 → 보급 상자를 열 수 있다.                                                        | 기계의 기능을 한눈에 읽고 성의 복원을 체험한다. 이동 중 재시도하면 줄·화물·보상이 같은 단계로 돌아와야 한다. 화물을 타고 필수 문을 건너뛰지 못하게 한다.         |
| 선택 · 서쪽 천문대        | 별자리판의 빈 홈, 같은 모양의 별무리 → 고리를 회전시켜 큰 별 세 점을 맞춘다 → 관측 기록의 날짜가 나타난다.                                                  | 도입부의 ‘변하지 않은 우주’와 사라진 기억을 잇는다. 별의 반짝임과 무관하게 풀리며, 고정된 실루엣과 버튼 미세조정을 제공한다.                                     |
| 선택 · 열람동과 원본 서고 | 대출 장부의 청구표와 반환함의 책표 → 같은 주제 표시를 대조해 책을 돌려놓는다 → 연관 인물의 짧은 기록이 드러난다.                                            | 서가를 수색할 이유를 준다. 긴 책등의 작은 글씨나 한자에 답을 숨기지 않고, 가까이 보면 장부에서 다시 읽을 수 있게 한다.                                           |
| 선택 · 전이문 너머 사냥터 | 훼손된 목록과 먹물 흔적 → 흔적을 따라 적을 찾아 처치하거나 위험 지대를 우회한다 → 보급품과 성장 보상을 회수한다.                                            | 사냥·스킬 사용을 연습하는 왕복 지선이다. 입구에 귀환 표식을 두고, 자원이 없어도 성으로 돌아오게 한다. 체크포인트 재시도로 같은 보상을 중복 수령하지 않아야 한다. |

## 채택 순서

제본 공방을 첫 선택 퍼즐로 권한다. 같은 재료가 접지·제본·원부·사진으로 이어지고 필수 동선에 새 문을 더할 필요가 없다. 하역기는 빗장을 연 뒤 성이 되살아난다는 보상에 잘 맞는다. 천문대와 서가 후보는 같은 장에서 순서를 외우는 과제가 겹치지 않도록 각각 공간 정렬과 분류에 집중한다.

기물의 치수와 회피 동선은 [설계 검토안](art/chapter-1/work-review.html), 챕터의 문·통로 관계는 [지상층 도면](art/chapter-1/library-route.svg)에서 확인할 수 있다.
