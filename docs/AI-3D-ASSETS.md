# 챕터 1용 3D 에셋 서비스

2026년 11월 23일 공식 문서 기준. 첫 유료 시안에는 **Meshy로 봉인문의 황동 잠금장식 한 개**를 권한다. 우리가 만든 정면·측면 시트를 입력하고, 삼각형 수와 텍스처 크기를 지정해 GLB를 받을 수 있다. 열람실 조명에서 문양이 읽히는지, 카툰 외곽선이 조각 사이를 메우는지 바로 비교할 수 있는 크기의 소품이다. 이번 조사는 문서와 로컬 Codex CLI의 연결 옵션을 확인한 것으로, 업체별 생성 품질을 실측한 결과는 없다.

| ------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

## 비용과 사용 조건

- **Meshy** 플러그인 생성은 유료 플랜과 크레딧이 필요하다. Meshy 7.1 기본 기하 품질에서 다중 이미지와 2K 텍스처 한 건은 30 API 크레딧이다. 리깅이나 재텍스처링 등은 추가 작업으로 계산한다. 권리를 보유한 입력으로 만들고 커뮤니티에 공개하지 않은 유료 결과물은 업체가 사용자 소유로 안내한다. [공식 단가표](https://docs.meshy.ai/en/api/pricing) · [결과물 소유 조건](https://help.meshy.ai/en/articles/10137554-what-is-the-ownership-of-the-generated-models)
- **Tripo**는 Studio와 개발자 API의 크레딧이 별도다. 개발자 약관 5.2절은 유료 사용자의 결과물에 수정·배포·수익화 권리를 명시한다. 국제 계정으로 CLI를 쓰는 경우 로그인 지역은 `ov`다. [과금 구분](https://www.tripo3d.ai/help/api-plugins/tripo-studiotripo-api) · [개발자 약관](https://developers.tripo3d.ai/en/terms) · [지역별 로그인](https://developers.tripo3d.ai/en/docs/cli)
- **Rodin** MCP는 로그인 때 선택한 워크스페이스의 플랜과 크레딧을 사용한다. 약관 5(b)는 약관·관련법·제3자 권리가 적용되는 범위에서 Rodin 출력의 이용을 허용한다. 비공개 설정도 제공한다. [MCP 과금](https://hyper3d.ai/features/mcp) · [Rodin 약관](https://hyper3d.ai/legal/terms?lang=en)

## 게임에 들여오는 기준

봉인 장식은 동일한 시트와 2K 텍스처로 받아 열람실에서 같은 거리로 비교한다. 손에 쥐는 도구는 기존 손잡이·화살 받침·완드 끝 기준점에 새 모델을 맞춘다. 활대, 시위, 빛살은 각각 움직이므로 분리된 상태로 확인한다. 서기관은 기존 골격에서 걷기·활 당기기·화살 꺼내기를 재생해 장갑과 소매 관통까지 확인할 수 있는 결과물을 채택한다. 채택한 파일에는 생성에 쓴 시트, 서비스와 작업 ID, 다운로드 당시 이용 조건을 함께 기록한다.
