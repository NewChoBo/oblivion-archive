# 서기관의 발 디딤과 착지

참고한 구현은 클래식 툼레이더를 재구현한 TRX의 `8561669`다. 걷다가 장애물에 막히면 현재 보행 프레임이 왼발과 오른발 중 어느 구간에 해당하는지 확인하고 정지 동작을 고른다. 전방 점프가 정상적으로 착지하면 전진·걷기 입력과 물속 여부에 따라 달리기 또는 정지로 이어진다. [걷기 충돌 처리](https://github.com/LostArtefacts/TRX/blob/8561669f69b1200b3dcf2f73bd424af893b67a7c/src/trx/game/lara/col/land.c#L255-L284) · [전방 점프 착지](https://github.com/LostArtefacts/TRX/blob/8561669f69b1200b3dcf2f73bd424af893b67a7c/src/trx/game/lara/col/jump.c#L389-L411)

현재 플레이어의 인간형 모델은 Ante Apocalypse의 Y Bot이다. 아래 측정은 당시 KayKit 리그로 수행했다. 현재 클립과 원본 파일 정보는 [인간형 에셋 기록](../asset-sources/Art/characters/BABYLON.md)에 있다.

## 서기관에 적용한 동작

- Y Bot의 앉기와 포복은 원래 체형 그대로 골반·척추·목·팔다리 관절을 움직인다. 서기에서 앉기까지 0.30초, 무릎과 손을 짚고 엎드리기까지 추가로 0.56초가 걸린다. 중간에 자세를 바꾸면 같은 동작을 현재 지점부터 되짚는다.
- 앉은 걸음과 포복의 한 주기는 각각 0.70m와 0.46m다. 실제 충돌 처리 후 이동한 거리로 클립을 진행한다. 전후좌우와 대각선 이동에서 디딘 발은 지면에 남고, 포복에서는 반대쪽 손과 발이 함께 몸을 민다. 장비 자세와 조준은 그 위에 적용한다.
- 전환 2개, 대기 2개, 방향별 이동 8개는 `public/assets/characters/ybot-postures.glb`에 들어 있다. `node --experimental-strip-types tools/bake-humanoid-postures.mjs`로 재생성한다. 다른 엔진에서는 같은 이름의 Mixamo 관절에 회전과 골반 위치 트랙을 연결하고, 캐릭터 이동 거리에 맞춰 재생한다.

- 출발할 때 걷기는 약 0.10초, 제자리에서 달리기는 약 0.17초에 각각 3m/s, 5m/s에 도달한다. 키를 떼면 걷기는 약 0.10m, 전력 질주는 약 0.28m 안에 멎는다. 프레임 안에서 충돌 검사를 여러 번 해도 제동 거리가 같다.
- KayKit 원본의 발목 궤적을 확인해 전진·후진·횡이동에 각기 다른 접지 구간을 잡았다. 충돌 처리 뒤 실제 이동한 거리로 보폭을 진행하고, 디딘 발목의 수평 위치를 바닥에 잡아 둔다. 발이 떨어지기 직전에 고정을 풀어 발끝의 구름 동작을 살린다.
- 제자리 점프는 실제 수직 속도에 맞춰 도약, 공중 자세, 착지로 이어진다. 움직이며 뛸 때는 마지막 발에서 다음 발로 무릎과 반대쪽 팔을 함께 내밀고, 바닥에 닿은 프레임에 실제 이동 방향으로 걷거나 달린다. 완드 발사와 활 충전은 상체만 전환한다.

## Orca에서 측정한 값

같은 입력 순서로 각 빌드에서 한 번씩 녹화했다. 아래 값은 지지하는 발의 발목이 보행 주기 중간에 바닥을 따라 움직인 평균 속도다. 두 빌드에 같은 위상 구간을 적용했다. 수정 후에도 출발과 방향 전환이 섞인 횡이동과 달리기에서는 미끄러짐이 남는다.

| 접지 중 발목의 수평 속도 | 이전 빌드 | 수정 빌드 |
| ------------------------ | --------: | --------: |
| 전진 걷기                |  2.009m/s |  0.063m/s |
| 전진 달리기              |  2.524m/s |  0.587m/s |
| 왼쪽 횡이동              |  1.680m/s |  1.277m/s |
| 뒷걸음                   |  2.832m/s |  0.001m/s |

발목 위치는 Orca에서 렌더 프레임마다 읽은 관절 좌표를 월드 좌표로 변환했다. 같은 클립·같은 발의 연속 프레임에서 수평 거리의 합을 경과 시간의 합으로 나눴고, 결과는 소수 셋째 자리까지 반올림했다. 달리며 착지한 프레임부터 달리기 자세를 선택하기까지 243ms가 걸리던 구간이 0ms로 줄었다. 제자리 착지는 두 빌드에서 모두 확인했다. [수정 전 기록](validation/2026-11-22/locomotion/before.json) · [수정 후 기록](validation/2026-11-22/locomotion/after.json) · [비교 영상](validation/index.html#locomotion)

최종 빌드에서 일반 메뉴 진입, 체크포인트 재도전, 봉인 해제, 귀환 통로, 사진 복원 엔딩까지 Orca 키·마우스로 진행했다. 완드와 활의 손 접촉 검사도 3,353프레임에서 통과했다. 커서 잠금은 이 실행에서 입장 시 호스트가 `WrongDocumentError`를 반환했고 캔버스 클릭 뒤에도 잠금을 확인하지 못했다.
