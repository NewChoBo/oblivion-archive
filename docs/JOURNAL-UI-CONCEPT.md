# 탐사 장부 UI 콘셉트

서재·탐사 모드의 인벤토리, 지도, 퀘스트를 **성채 기록관이 들고 다니는 장부 한 권**으로 묶는다. 장비를 고를 때는 물건을, 길을 찾을 때는 도면을, 단서를 읽을 때는 기록을 크게 보여준다. 셋은 같은 색인과 조작법을 쓰되 본문 구성은 각 행동에 맞춘다.

## 참고한 두 가지 흐름

- 스카이림의 물품 메뉴에서는 분류를 좁히고 목록을 옮겨 다니면서 선택한 물건의 외형과 정보를 함께 본다. 퀘스트 일지에서는 선택한 목표의 위치를 곧바로 지도에서 확인한다. 서재에서는 이 두 흐름을 장비 비교와 단서 조사에 적용한다. [Bethesda의 Skyrim PC 매뉴얼, Items·Journal](https://assets.ctfassets.net/rporu91m20dc/1poliwondakI2QwKQMY2QI/b79ecee4541dd1ba7c7a85b453f0e9b2/manual_skyrim-le_pc_en-us.pdf)
- 위쳐 3는 추적 중인 퀘스트의 다음 행동을 HUD에 쓰고 근처 목표의 위치를 미니맵에 보여준다. 서재에서도 일지를 닫았을 때 **무엇을 할지**는 한 줄로, **어디로 갈지**는 미니맵으로 이어간다. [CD PROJEKT RED의 위쳐 3 PC 매뉴얼, Game Interface](https://cdn-l-thewitcher.cdprojektred.com/media/TW3/Pdf/Manuals/PC/The_Witcher_3_Wild_Hunt_Game_Manual_PC_EN.pdf)

## 책을 펼쳤을 때

먹빛 가죽 표지 안에 따뜻한 회백색 종이와 낡은 황동 책갈피가 보인다. 인벤토리의 물건은 측면에서 횃불을 받은 듯한 정물 삽화로, 지도는 검은 바탕 위에 밝은 잉크로 그린 성채 평면도로 표현한다. 금박은 선택한 항목과 추적 중인 목표에만 쓴다. 제목은 세리프, 본문·수량·키 안내는 작은 화면에서도 읽히는 서체를 쓴다. 선택은 테두리, 추적은 책갈피 모양으로도 구별한다.

| 책갈피             | 펼쳤을 때 보이는 것                                                                                                                                   | 주요 행동                                                                                                                                           |
| ------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| Inventory · 소지품 | 왼쪽은 장착 중·가방 목록, 오른쪽은 선택한 물건의 삽화와 쓰임새. 활은 화살통 수량과 시위에 건 상태, 완드는 충전량을 표시한다.                          | 같은 종류의 장비를 골라 현재 장비와 비교한 뒤 장착한다. 궤짝 앞에서 열면 가방과 보관함이 나란히 열린다. 기존 성장 화면은 이곳의 보조 항목으로 둔다. |
| Map · 지도         | 현재 층의 도면을 화면 가득 펼친다. 계단참에는 연결 층을 적고, 플레이어의 자리는 점과 시야 부채꼴로 나타낸다. 추적 지점에만 금빛 책갈피 하나를 꽂는다. | 층 전환, 확대·축소, 내 위치로 복귀. 다른 층의 목표를 추적하면 현재 층에서는 연결 계단을, 목적 층에서는 조사할 구역을 강조한다.                      |
| Quests · 의뢰      | 왼쪽에 본편과 미라의 선택 의뢰를 구분한다. 오른쪽은 현재 할 일부터 시작해 발견한 단서와 끝낸 단계를 시간순으로 보여준다.                              | 한 건을 추적하거나 지도에서 위치를 연다. 관련 사진이나 기록을 읽고 돌아오면 같은 의뢰와 스크롤 위치를 복원한다.                                     |
| Codex · 설정집     | 수집한 기록과 조사한 단서를 읽는 서가. 퀘스트에서 넘겨온 경우 해당 기록을 바로 펼친다.                                                                | 삽화와 원문을 읽고 이전 화면으로 돌아간다. 미발견 기록은 제목과 내용이 드러나기 전까지 수집 개수로 표시한다.                                        |

**첫 챕터의 예시.** ‘사진에서 지워진 사람’을 추적하고 지도를 열면 서재 열람실이 강조된다. 장부를 덮으면 HUD에는 ‘중앙 기록대의 빛바랜 사진을 조사하세요’ 한 줄이 남는다. 실제로 사진을 조사한 순간 장부에 사진 뒷면의 글이 들어온다. 다음 목적지가 아직 단서로만 알려졌다면 지도에도 그 정도의 정보만 적는다. 봉인의 정답이나 미발견 통로는 플레이어가 찾아낸 뒤에 기록한다.

## 조작과 모드

- 기존 장부 키(기본 Tab)와 사용자 지정 키로 마지막 책갈피를 다시 연다. 지도 M, 의뢰 J는 직접 열기 기본값 후보이며 재지정을 지원하는 방향이다. 퀘스트에서 지도로 건너간 뒤 ‘뒤로’를 누르면 원래 의뢰로 돌아온다. 최상위에서 닫으면 게임으로 복귀한다.
- 데스크톱은 목록과 상세를 함께 펼친다. 최소 지원 크기 **568×320**에서는 목록 → 상세 한 면씩 전환한다. 지도에서는 본문 전체를 도면에 쓰고 장소를 누를 때만 설명을 펼친다. 장착, 추적, 층 전환은 터치로도 선택할 수 있어야 한다.
- 서재·탐사는 기존 장부의 일시정지 동작을 따른다. 전술 모드는 전장 지도와 라운드 목표를 사용하고, 멀티플레이에서는 지도 열람을 개인 UI 상태로 다룬다. 영어 원문과 한국어 알파 양쪽에서 긴 목표명과 줄바꿈을 확인한다.

## 다음 설계 순서

1. **정적 시안** — 같은 저장 상태로 활 장착, 열람실 지도, 사진 의뢰 세 장을 그린다. 데스크톱과 최소 가로 화면에서 선택 항목, 다음 행동, 닫기 위치를 구별할 수 있는지 본다.
2. **조작 시안** — ‘의뢰에서 지도 보기 → 게임 복귀 → 사진 조사 → 기록 읽기’와 ‘궤짝에서 장비 비교 → 장착’ 두 흐름만 연결한다. 기존 키 설정과 뒤로 가기, 키보드 포커스 복원을 확인한다.
3. **구현 경계** — 전체 지도와 미니맵은 같은 층·좌표·장소 ID를 읽고, 장부와 HUD는 같은 목표 ID를 읽도록 설계한다. 추적 선택과 마지막 책갈피는 개인 상태, 장비 소유와 퀘스트 완료는 세션 상태로 둔다. 장부를 여는 경로에는 별도 3D 씬이나 장비 모델 로딩이 필요하지 않도록 기존 삽화를 우선 사용한다.
