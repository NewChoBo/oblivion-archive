# 런앤레이드 네 캐릭터의 교전과 회피

시각은 각 영상의 재생 위치다. 카이켄의 조준과 발사는 0.2초 간격으로, 스위프트의 돌진과 해머의 착지는 0.25~0.5초 간격으로 다시 확인했다. 색이 다른 피해 숫자나 동시에 터진 번개만으로 공격자를 정하기 어려운 곳은 당시 스킬 설명과 플레이어 공략으로 보완했다.

## 웹판에서 정한 값

웹판은 30Hz 단위로 이동과 충돌을 계산한다. 카이켄 반월의 점프 통과 기준은 발높이 0.48m, 상월의 방향은 중앙과 좌우 약 19.5도다. 같은 상월의 여러 갈래가 만나는 자리에서는 대상당 한 번 피해를 준다. 릴딘의 연속베기는 첫 세 번이 다음 평타를 열며, 마지막 베기는 한 번의 피해로 처리한다. 스위프트의 복수는 잃은 체력에 따른 확률을 공격마다 누적해 방장과 참가자가 같은 치명타를 재생한다. 피해량·경직 시간·재사용 시간과 모델·동작은 웹판의 전투 속도에 맞췄다.
