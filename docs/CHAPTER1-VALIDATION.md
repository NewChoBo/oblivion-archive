## 호스트 제한과 남은 확인

- **실제 커서 잠금·잠금 상태 Esc 해제·재진입:** Orca가 `WrongDocumentError`로 거절했다. 선택한 자유 시점과 메뉴 재개를 검증했으며 무제한 마우스 잠금 성공으로 보고하지 않는다. 다른 브라우저로 대체하지 않았다.
- **공중에서 빠르게 두 번 누르는 실제 입력:** Orca 명령 왕복이 비행 시간보다 길어 네이티브 연타 증거는 없다. 공중 재요청 거절은 단위 검사, 벽 옆 실제 점프·착지는 프레임 관찰로 확인했다.
- **물리 스피커와 사람의 청취 평가:** 실제 믹스·PCM·WAV까지만 확인했다. 소리의 구분감·청취 음량 평가는 녹음을 통해 확인할 수 있다.
- **경계 조합 전체:** 아치 아래 달리며 점프, 회랑 잔해의 모든 대각선·모서리, 문이 움직이는 매 순간의 1·3인칭 카메라·캐릭터·극근접 발사 조합은 전수 검사하지 않았다. 일반 통행·닫힘과 개방 뒤 통과·대표 벽 카메라는 확인했다.
- **미술과 성능:** 위 완주 기록은 초기 캐릭터로 진행했다. 후속 캐릭터의 동작은 별도 영상에서 볼 수 있다. 금속 적중의 별도 실입력 비교, 기기별 FPS·메모리·장기 안정성은 후속 확인이다.

[캡처·영상·오디오 모아 보기](http://127.0.0.1:5186/docs/validation/index.html)는 신규 개발 서버에서 제공한다. 재현 스크립트는 `tools/chapter-walkthrough.ps1`, `tools/controls-acceptance.ps1`, `tools/magic-acceptance.ps1`, `tools/contact-threat-acceptance.ps1`이다. 입력 시간은 이 PC의 Orca 왕복 지연에 맞춰져 있으므로 다른 레이아웃·기기에서는 구간별 상태 기록을 확인하며 조정한다.
